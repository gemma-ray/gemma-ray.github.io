# La cançó de fons

Poseu aquí el fitxer de la cançó i escriviu-ne el camí a `script.js`:

```js
music: {
  file: "assets/audio/fly-me-to-the-moon.mp3",
  volume: 0.35
}
```

Mentre `file` estigui buit, el botó de música no apareix al web.

## Per què no es pot posar l'enllaç de Spotify

Spotify no deixa que una altra web li agafi una cançó i la posi de fons.
Només permet **incrustar el seu reproductor**, que surt com una finestra
seva, amb la seva caràtula i els seus botons, i el convidat ha de prémer
play. No es pot fer que soni sol ni sense que es vegi el reproductor.

Per tenir música de fons de veritat cal un fitxer al mateix web.

## Format

- **MP3** (o M4A). Qualsevol ordinador i mòbil el llegeix.
- Si el podeu deixar per sota dels **4 MB**, millor: es carrega abans.
- No cal que duri tota la cançó; es repeteix sola.

## Un avís

«Fly Me to the Moon» té drets d'autor. Per a un web privat de casament,
amb contrasenya i sense ànim de lucre, és una pràctica habitual, però
tècnicament el fitxer no es pot allotjar sense llicència. Ho decidiu
vosaltres; només volem que ho sapigueu.
